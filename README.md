# Grandma Clock

A simple, high-contrast Android analog clock designed for easy reading.

- Large analog clock face
- Smooth second hand
- High contrast black/white/red design
- Keeps the display awake while the app is open
- Portrait orientation

GitHub Actions builds a debug APK automatically on every push to `main`.

Note: Android apps cannot force the screen to remain lit while the device is locked; this app keeps the screen awake while it is running in the foreground.
